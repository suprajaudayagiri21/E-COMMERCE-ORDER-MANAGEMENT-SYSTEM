# E-COMMERCE-ORDER-MANAGEMENT-SYSTEM

## Project Overview
The **E-Commerce Order Management System** is a DBMS-based project designed to manage customers, products, orders, payments, inventory, and shipments efficiently. It uses a relational database to store and organize data with primary keys, foreign keys, and integrity constraints.

## Objectives
- Manage customer information.
- Maintain product details, prices, and stock quantities.
- Create and track customer orders.
- Store payment details and payment status.
- Manage shipment and delivery information.
- Retrieve useful information using SQL queries.

## Database Tables
The project contains the following six tables:

1. **Customer** – Stores customer details.
2. **Product** – Stores product information, prices, and stock.
3. **Orders** – Stores order details and order status.
4. **OrderItem** – Stores products and quantities in each order.
5. **Payment** – Stores payment information and status.
6. **Shipment** – Stores tracking and delivery details.

## Technologies Used
- **Database:** Relational Database
- **Query Language:** SQL
- **Version Control:** GitHub

## SQL Concepts Used
- DDL and DML commands
- Primary and Foreign Keys
- NOT NULL, UNIQUE, CHECK, and DEFAULT constraints
- SELECT, INSERT, and UPDATE statements
- JOIN operations
- Aggregate functions
- GROUP BY and subqueries
